# GridCast Studio 原型验收记录

验收日期：2026-09-16。验收对象：当前工作区的本地科研原型。

## 1. 结论与证据边界

四模块已经形成可运行闭环：数据导入与版本管理 → 真实模型训练 → 版本发布与预测 → 点预测、经验区间、解释与实际值回流 → 受控候选重训。

本记录是开发环境的功能与冒烟验证，不是导师或项目方的最终业务验收，不证明真实场景的精度、生产安全等级、并发能力或合同全部指标。

- 正式本机入口：`http://127.0.0.1:8000`，使用默认 `.data`，交付检查时未创建管理员、未注入测试数据。
- 测试入口：`http://127.0.0.1:8001`，使用独立 `.qa/smoke-data`，账号和数据均只用于测试。
- 云端模式使用独立 `.qa/cloud-check` 通过应用测试客户端验证；没有部署到外部服务器，也没有运行 Docker。
- 以下预测指标全部来自合成负荷，不可作为真实电力业务效果证据。

## 4. 合成数据结果摘录

初始合成数据为 90 天小时级负荷、数据版本 v1、24 步预测。以下指标取自相同版本的独立测试窗口，默认名义区间为 95%。

| 模型 | 测试 MAE / kW | 实测区间覆盖率 |
|---|---:|---:|
| 季节朴素基线 | 51.3552 | 95.4545% |
| 集成树 + 残差校准 | 23.5260 | 96.9697% |
| 选择性状态递推 + 稀疏上下文注意力混合模型，2 epoch | 42.0902 | 96.5909% |

- 混合模型仅验证训练推理链路，不代表调优结果，也不是官方 Mamba 复现。
- 对同一预测输入测试的 80% / 90% / 95% 区间平均宽度约为 90.29 / 132.86 / 164.12 kW；这里只证明该用例的区间顺序和数值有效性。
- 增量自适应用例中，旧模型与候选在同一更新测试窗的 MAE 分别约为 23.9230 / 23.4503 kW。候选保持待发布，旧模型保持上线。
- 后续浏览器新训练的 v2 季节基线 MAE 为 47.4173 kW，不能与上表 v1 直接排名。
- 名义区间水平不等于实测覆盖率；上述结果不提供任意未来时间序列上的覆盖保证。

## 5. 可复核材料与演示步骤

页面截图保存在 `.qa`：

- `dashboard-final.png`：最终总览，包含真实模型输出、区间、敏感度和版本状态。
- `predict-desktop.png`、`predict-mobile.png`：预测结果的桌面与手机布局。

这些截图来自测试实例，不表示正式入口已经有业务数据。`.qa` 是本地测试输出，不需要作为运行依赖分发。

建议使用自己的新账号在正式入口复核：

1. 创建管理员，初始化演示场景，等待训练、回测和未来预测任务完成。
2. 查看预测曲线、区间、敏感度和留出评估；确认未来误差在标签到达前不显示虚构数值。
3. 训练同版本的基线或混合模型，查看任务日志和模型对比，手动发布或回滚。
4. 追加演示观测，检查历史预测实际值、回流误差和监测事件。
5. 按需要启用自适应门槛，确认候选需要人工审核上线。
6. 按模板导入自己的 CSV，使用真实场景重新训练和评估。

详细配置和安全部署说明见根目录 `README.md`；逐项需求边界见 `docs/需求覆盖与阶段规划.md`。

- 未使用用户真实业务数据验证“高精度”，没有承诺固定 MAE、MAPE 或统一准确率。
- 未执行 Docker 构建、云服务器部署、HTTPS 反向代理验收或多机同步；当前云端方案是单实例持久化部署配置。
- 未进行生产并发、最大数据量、长期稳定性、外网渗透或量化低于 1 秒的性能验收。
- 未接电表、MQTT、Kafka 或外部实时采集服务；“实时”指追加接口接入、后台处理与每 4 秒界面刷新。
- 自适应是监测驱动的批量重训，不是逐条在线参数更新；候选发布由管理员控制。
- 解释采用分组扰动 / 通道遮蔽，不是 SHAP，也不证明因果关系。
- 时序分解为 STL，未实现 CEEMDAN；PDF 为浏览器打印，非服务器直接生成。
- 未验证正式 Mamba 模型、GPU 训练、多城市部署、论文、专利或经济效益。
