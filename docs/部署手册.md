# GridCast Studio 部署手册

面向把本原型交付给他人或部署到 Linux 服务器的场景。两种方式二选一：**Docker Compose（推荐）** 或 **裸机 systemd + Nginx**。Windows 本机演示直接用仓库根目录 `start.cmd`，不在本手册范围内。

> 边界提醒：本系统是科研原型，SQLite 单实例设计。仅允许运行**一个 API 进程 + 一个计算 worker**，不支持多副本负载均衡；公网暴露必须走 HTTPS。

## 1. 交付物与运行要求

交付 zip（`scripts/make_release.py` 生成）包含源码、预构建前端（`frontend/dist`，接收方无需安装 Node.js）、部署配置和文档。

| 项目 | 要求 |
|---|---|
| 操作系统 | Linux x86_64（Docker 方式任意发行版；裸机方式 Debian/Ubuntu 为例） |
| 内存 | ≥ 2 GB（PyTorch 混合模型训练建议 4 GB） |
| 磁盘 | ≥ 5 GB（镜像 + 数据；数据随数据集和模型数量增长） |
| 软件 | Docker 方式：Docker Engine ≥ 24 + compose 插件；裸机方式：Python 3.12、Nginx |
| 网络 | 仅需暴露一个 HTTPS 入口；应用自身绑定 `127.0.0.1:8000` |

## 2. 方式一：Docker Compose（推荐）

镜像内已含 CPU 版 PyTorch，前端在构建阶段编译，启动即用。

```bash
unzip gridcast-*.zip && cd gridcast-*

cp .env.example .env
# 编辑 .env，必须设置：
#   APP_SETUP_TOKEN=不少于16位的随机串   （首次初始化管理员所需）
#   APP_PUBLIC_ORIGIN=https://你的域名    （有域名和 HTTPS 时）
#   APP_COOKIE_SECURE=true               （HTTPS 下必须）
```

生成随机令牌示例：`openssl rand -hex 24`。

```bash
docker compose up --build -d
docker compose logs -f gridcast     # 观察启动日志，Ctrl+C 退出查看
curl http://127.0.0.1:8000/api/health
```

说明：

- 应用端口只映射到宿主机回环（`127.0.0.1:8000`），公网访问需由宿主机 Nginx/Caddy 等反代到该地址并配置 HTTPS（可参考 `deploy/nginx-gridcast.conf`）。
- 数据持久化在命名卷 `gridcast_data`。**不要执行任何会删除该卷的操作**（如 `docker compose down -v`）。
- 只需季节基线与集成树、不需要 PyTorch 混合模型时，在 `.env` 设 `INSTALL_HYBRID=false` 可显著减小镜像体积。
- 升级：`docker compose build --no-cache && docker compose up -d`。数据卷保留即数据保留。

## 3. 方式二：裸机 systemd + Nginx

以 Ubuntu/Debian 为例，假设安装到 `/opt/gridcast`，专用用户 `gridcast`。

```bash
# 1) 用户与目录
sudo useradd --create-home --system gridcast
sudo mkdir -p /opt/gridcast && sudo chown gridcast:gridcast /opt/gridcast

# 2) 解压交付包（在本机解压后上传，或直接上传 zip 后在服务器解压）
sudo -u gridcast unzip gridcast-*.zip -d /opt/gridcast_tmp
sudo cp -r /opt/gridcast_tmp/gridcast-*/. /opt/gridcast/ && sudo rm -rf /opt/gridcast_tmp

# 3) 虚拟环境与依赖（混合模型需要 CPU PyTorch）
cd /opt/gridcast
sudo -u gridcast python3.12 -m venv .venv
sudo -u gridcast .venv/bin/pip install -r requirements.txt
sudo -u gridcast .venv/bin/pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu

# 4) 配置
sudo -u gridcast cp .env.example .env
sudo -u gridcast nano .env
#   APP_MODE=cloud
#   APP_HOST=127.0.0.1
#   APP_SETUP_TOKEN=<随机串>
#   APP_PUBLIC_ORIGIN=https://你的域名
#   APP_COOKIE_SECURE=true
```

systemd 服务（配置文件在交付包 `deploy/gridcast.service`）：

```bash
sudo cp deploy/gridcast.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gridcast
systemctl status gridcast --no-pager
curl http://127.0.0.1:8000/api/health
```

Nginx + 证书（示例，证书路径按实际替换）：

```bash
sudo apt install nginx certbot python3-certbot-nginx
sudo cp deploy/nginx-gridcast.conf /etc/nginx/sites-available/gridcast.conf
sudo ln -s /etc/nginx/sites-available/gridcast.conf /etc/nginx/sites-enabled/
sudo certbot --nginx -d 你的域名          # 自动改写证书路径
sudo nginx -t && sudo systemctl reload nginx
```

## 4. 首次初始化

1. 浏览器打开 `https://你的域名`。
2. 首次进入初始化页面，创建管理员账号并填入服务器上配置的 `APP_SETUP_TOKEN`。
3. 登录后到“总览”页点击“初始化演示场景”，可一键生成合成数据、训练并发布演示模型，用于快速验收界面与流程。
4. 正式使用：在“数据管理”上传真实 CSV（格式约定见主 README 第 3 节），在“训练与模型”发起训练。

## 5. 备份、恢复与迁移

自本版本起，数据库中的数据集与模型文件路径为**相对路径**，`.data` 目录整体拷贝即可跨机器/跨路径迁移，无需手工改库。旧版本数据库（绝对路径）在服务启动时会自动迁移为相对路径。

```bash
# 备份（Docker 方式）
docker compose stop && sudo tar czf gridcast-backup-$(date +%F).tgz /var/lib/docker/volumes/gridcast_gridcast_data
docker compose start
# 备份（裸机方式）
sudo systemctl stop gridcast && sudo tar czf gridcast-backup-$(date +%F).tgz -C /opt/gridcast .data
sudo systemctl start gridcast

# 恢复 / 迁移到新服务器
# 1) 停止应用；2) 将整个 .data（或数据卷内容）放回同结构位置；3) 启动应用。
```

注意：备份必须在应用停止后进行（SQLite WAL 模式下热拷贝可能不一致）。恢复后首次启动会自动完成路径兼容处理。

## 6. 故障排查

| 现象 | 处理 |
|---|---|
| `/api/health` 不通 | `docker compose logs gridcast` 或 `journalctl -u gridcast -e`；确认 8000 端口未被占用 |
| 初始化页面报令牌错误 | 核对 `.env` 的 `APP_SETUP_TOKEN` 与页面填写值；修改后需重启服务 |
| 登录后无法访问、Cookie 不保持 | HTTPS 下必须 `APP_COOKIE_SECURE=true`；有域名时设置 `APP_PUBLIC_ORIGIN` |
| 上传 413 | 反代层 `client_max_body_size` 需 ≥ 25m（见 nginx 示例） |
| 训练任务一直排队 | worker 随应用进程启动；查日志确认计算进程在线，确认没有同时运行多个实例 |
| 迁移数据后模型/数据集打不开 | 确认拷贝的是**完整** `.data` 目录（含 `datasets/`、`models/`、`gridcast.db`、`.jwt-secret`） |

## 7. 上线检查清单

- [ ] HTTPS 有效，`APP_COOKIE_SECURE=true`
- [ ] `APP_SETUP_TOKEN` 为随机值且未写入版本库
- [ ] 应用仅监听 `127.0.0.1`，公网入口只有反代 443
- [ ] 仅一个 API 实例 + 一个 worker 在运行
- [ ] 已做一次成功备份，并在测试环境验证过恢复
- [ ] 磁盘空间与日志轮转（journald / docker logging driver）已配置
- [ ] 向接收方交付了访问地址、管理员创建方式与本手册
